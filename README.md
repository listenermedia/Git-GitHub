# Git-GitHub

A Git and GitHub workshop by Muhammed Sanweer KT, with a responsive single-page portfolio.

## Open the portfolio

Open `index.html` in a browser. No installation, build tools or external assets are required.

## Classroom materials

- [Student guide](STUDENTS.md): manual file edits, Git commands, expected changes and publishing steps.
- [Teacher guide](TEACHER.md): full-day schedule, checkpoints and PPT mapping.

The portfolio uses semantic HTML and CSS, responsive layouts, keyboard focus styles and reduced-motion support. All illustration is created in CSS.

## Make it yours

Edit the name, introduction, About paragraphs, GitHub links, projects and footer in index.html. The student guide provides a staged walkthrough. The sample portfolio identifies the workshop author; students should replace it with their own content.

## GitHub Pages

In repository Settings → Pages, select deployment from main and /(root), then save. Use the deployment URL reported by GitHub.

The original classroom PDF is retained locally and excluded from Git.
